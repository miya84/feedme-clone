# URL → Markdown → LLM

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 변환해 보여 주고, 복사·다운로드하거나 ChatGPT·Claude 새 채팅으로 바로 넘기는 한 페이지짜리 서비스.

## 사용자에게 보이는 결과

한 화면(`/`)에서 아래 흐름이 끊김 없이 이어진다. 현재의 템플릿 안내 화면은 이 서비스 화면으로 대체된다. UI 문구는 한국어다.

1. **입력** — URL 입력칸에 주소를 붙여넣고 변환을 실행한다. 지우기 버튼을 누르면 입력과 결과가 모두 초기 상태로 돌아간다.
2. **변환** — 페이지 본문만 Markdown으로 추출된다. 변환 중에는 진행 중임이 보이고, 그동안 중복 실행은 막힌다.
3. **결과 확인** — 결과 영역 맨 위에 페이지 제목, 저자(알 수 있을 때만), 원문 도메인이 헤더로 보인다. 프롬프트 선택과 내보내기 버튼은 헤더 바로 아래, 본문보다 위에 있어 긴 글도 스크롤하지 않고 내보낼 수 있다. 그 아래에 Markdown이 렌더링되어 보인다(제목 계층, 목록, 링크, 코드 블록, 굵게·기울임이 서식대로 보인다). 변환에 실패하면 결과 자리에 이유와 "다시 시도" 버튼이 보이고, 다시 시도는 같은 주소로 변환을 다시 실행한다.
4. **프롬프트(선택)** — `요약해줘` / `한국어로 번역해줘` / `쉽게 설명해줘` 프리셋과 `직접 입력` 중 하나를 고르거나, 아무것도 고르지 않을 수 있다(기본은 선택 없음). `직접 입력`을 고르면 텍스트 입력칸이 나타나고, 이 입력은 1회용이라 저장하지 않는다(새로고침하거나 지우기를 누르면 사라진다). 프리셋 선택을 다시 누르면 선택이 해제된다.
5. **내보내기**
   - **복사하기** — Markdown을 클립보드에 복사하고 복사됐음을 알린다.
   - **.md 다운로드** — Markdown을 `.md` 파일로 내려받는다. 파일 이름은 페이지 제목에서 만든다.
   - **ChatGPT로 열기 / Claude로 열기** — 프롬프트(고른 경우)와 Markdown 전체를 클립보드에 복사하고, 새 탭에서 해당 서비스의 새 채팅을 연다. 사용자는 채팅창에 붙여넣기만 하면 되며, 붙여넣기가 필요하다는 안내가 함께 보인다. 프롬프트는 Markdown 앞에 빈 줄을 두고 붙는다. 프롬프트를 고르지 않으면 Markdown만 복사된다.
6. **다크모드 토글** — 화면 어디서든 라이트/다크를 전환할 수 있다.

내보내는 Markdown(복사·다운로드·LLM 전달 공통)은 맨 앞에 `# 제목` 줄과(저자가 있으면) 저자 줄을 붙인 본문이다.

## 승인된 범위

- URL 한 건을 변환하는 단일 화면. 변환은 defuddle 라이브러리로 한다(필수).
- 복사, .md 다운로드, ChatGPT·Claude 새 채팅 열기.
- 프롬프트 프리셋 3종과 1회용 직접 입력.
- 라이트/다크 토글.

## 수용 기준

1. 본문이 있는 공개 글 URL을 넣고 변환하면 결과 헤더에 그 페이지의 제목이 보이고, 저자 정보가 있는 페이지는 저자도 보인다. 본문 아래에 렌더링된 Markdown이 보이며 메뉴·푸터 같은 본문 외 요소는 들어 있지 않다.
2. 지우기 버튼을 누르면 URL 입력칸, 결과, 고른 프롬프트, 직접 입력 텍스트가 모두 초기 상태가 된다.
3. 복사하기를 누르면 클립보드에 내보내는 Markdown(맨 앞 `# 제목` 포함)이 들어 있고 복사 완료가 화면에 알려진다.
4. .md 다운로드를 누르면 같은 Markdown이 `.md` 파일로 내려받아지고, 파일 이름에 페이지 제목이 반영된다.
5. 프롬프트를 고르고 ChatGPT(또는 Claude)로 열기를 누르면 클립보드에 `프롬프트 + 빈 줄 + Markdown`이 들어가고, 새 탭에서 해당 서비스의 새 채팅 화면이 열린다. 프롬프트를 고르지 않으면 클립보드에 Markdown만 들어간다.
6. `직접 입력`을 고르면 입력칸이 나타나고, 입력한 문장이 5번의 프롬프트로 쓰인다. 새로고침 후에는 그 문장이 남아 있지 않다. 다른 프리셋으로 바꾸면 입력칸이 사라지고 프리셋 문구가 쓰인다.
7. 형식이 잘못된 입력(비어 있음, `http`/`https`가 아닌 주소)은 변환을 시작하지 않고 입력칸 근처에 이유를 보여 준다. 접속 실패·본문 추출 실패(빈 결과)는 결과 영역에 오류로 표시되고, 이전 결과가 새 오류와 함께 남지 않는다.
8. 다크모드 토글로 화면 전체가 라이트/다크로 바뀌고 두 모드 모두에서 본문과 컨트롤이 읽힌다.
9. 좁은 화면(모바일 폭)에서도 입력, 결과, 내보내기·프롬프트 컨트롤이 모두 사용 가능하다.

## 설정된 제약과 근거

- **변환은 서버 쪽에서 한다.** 브라우저는 임의의 다른 사이트 HTML을 직접 읽을 수 없고(교차 출처 제한), defuddle의 Node 진입점(`defuddle/node`)은 URL을 받아 직접 가져오지 않고 HTML 문자열과 DOM 구현(linkedom 등)을 받는다. 그래서 서버가 URL의 HTML을 가져와 defuddle로 변환한다. 호스팅 서비스 defuddle.md는 무료 한도를 넘으면 구매·API 키가 필요하다고 문서에 적혀 있어 쓰지 않는다. (scratch에서 defuddle 0.19.6으로 HTML 문자열 입력 → 제목·저자·본문 Markdown 추출이 되는 것을 확인했다. 이 환경은 외부 사이트 접속이 막혀 실제 공개 페이지로는 확인하지 못했다.)
- **LLM 전달은 클립보드 + 새 채팅 열기.** 주소의 `?q=` 파라미터로 보내는 방식은 길이 제한 때문에 긴 글이 잘리거나 열리지 않을 수 있어, 글 길이와 상관없이 같게 동작하는 방식을 택했다. (사용자 확정)
- 화면 구성은 [ui-composition](../../decisions/ui-composition.md)을 따른다. 새 의존성은 [dependency-versions](../../decisions/dependency-versions.md)의 정책을 따른다.

## 가정 (덮어쓸 수 있음)

- 입력은 변환 실행 버튼(또는 Enter)으로 시작한다. 붙여넣기만으로 자동 실행하지 않는다.
- 변환 결과는 서버에 저장하지 않는다. 새로고침하면 결과는 사라진다.
- 다크모드의 첫 상태는 사용자의 시스템 설정을 따르고, 사용자가 토글로 고르면 그 선택을 이 브라우저에 기억한다. (1회용 직접 입력 프롬프트의 "저장하지 않음"과는 별개다.)
- 저자를 알 수 없으면 저자 줄은 보이지 않는다. 제목을 알 수 없으면 입력한 주소의 호스트 이름을 제목 대신 쓴다.
- 로그인이 필요한 페이지, 자바스크립트로 본문을 그리는 페이지는 본문을 못 얻을 수 있고, 그때는 추출 실패 오류로 처리한다.
- 프리셋 문구는 버튼 이름 그대로("요약해줘", "한국어로 번역해줘", "쉽게 설명해줘")를 프롬프트로 쓴다.

## 범위 밖과 이유

- 변환 이력·계정·서버 저장 — 요구에 없고 저장 시 개인정보 부담이 생긴다.
- 여러 URL 일괄 변환 — 요구는 URL 한 건 흐름이다.
- LLM 응답을 이 서비스 안에서 보여 주는 기능 — 이 서비스는 LLM으로 "넘기는" 데까지만 맡는다.
- 보안 하드닝·성능 방어(요청 한도, 사설망 주소 차단 등) — 이 템플릿의 검증 예산(AGENTS.md)에서 스펙이 요구하지 않은 하드닝은 범위 밖이다. 아래 남은 위험에 적는다.

## 남은 위험

- 서버가 사용자가 준 임의의 URL을 가져오므로, 공개 배포 시 사설망 주소 접근(SSRF)과 남용에 노출된다. 로컬·강의용 사용에서는 허용하는 위험이며, 공개 배포를 결정하는 시점에 별도 스펙으로 다룬다.
- 일부 사이트는 서버의 요청을 막거나(봇 차단) 본문이 자바스크립트로만 그려져 변환이 실패할 수 있다.
- 클립보드 복사는 사용자 동작(클릭) 안에서만 허용되는 브라우저가 있다. 변환 결과를 가져온 뒤가 아니라 이미 화면에 있는 결과에 대해 클릭 시점에 복사하므로 영향은 작지만, 브라우저별 동작은 구현에서 실제 화면으로 확인한다.
